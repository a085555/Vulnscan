ABOUT

Vulnscan Security Workspace is a controlled browser security scanner. Installed version: v6.5.0.

  • Passive inspects the loaded page without sending scanner-generated requests.
  • Safe Active allows same-origin GET, HEAD, and OPTIONS checks within a request budget.
  • Lab performs controlled, soft-404-aware path discovery.
  • Full Scan runs Passive, Safe Active, and Lab in order under one shared request budget.
  • Selectable checks let you run only the check families relevant to the target.
  • Scan comparison highlights new, changed, resolved, and unchanged results against the last matching scan.
  • Investigation view adds impact, remediation, verification steps, technical metadata, and a local workflow state to every result.
  • Interactive scan map connects observed surfaces, scan stages, checks, and related results.
  • Journey Capture follows one authorized tab and records a redacted, passive view of page changes, same-origin API metadata, and grouped findings.
  • Guided exploitability explains prerequisites, safe validation, and evidence that may disprove a finding.
  • Cross-browser builds support desktop Chrome and Firefox from the same source.

Site access is requested for the exact selected origin and released when the scan finishes. If response headers need a manual refresh, access is limited to the selected tab and expires after 10 minutes. Scan reports and history are stored locally. Raw secret values stay in browser session memory and only leave it through the separate full-secret export.
