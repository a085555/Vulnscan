// ABOUT

VulnScan Ultimate is a controlled browser security scanner. Installed version: v5.3.0.

  • Passive inspects the loaded page without sending scanner-generated requests.
  • Safe Active allows same-origin GET, HEAD, and OPTIONS checks within a request budget.
  • Lab adds controlled path discovery for targets you are explicitly authorized to test.

Site access is requested for the exact selected origin so the extension can inspect that tab. Scan reports and history are stored locally. Raw secret values stay in browser session memory and only leave it through the separate full-secret export.
